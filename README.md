# Captures of the validation of ppk2-lib

The six captures of the round of 2026-11-21: Nordic's Power Profiler app
and `ppk2 capture`, in Ampere meter mode and in Source meter mode. They
are kept on this branch, apart from `main`, so that installing the
package does not download them.

`validation/evidence/bench_dut/README.md` on `main` says what they are
and how to use them.
